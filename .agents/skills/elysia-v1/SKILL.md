# Elysia 1.x in MemeOver

Check the Elysia version in [bun.lock](../../../bun.lock) and read
[bot conventions](../../../bot/AGENTS.md). Confirm API signatures in
`bot/node_modules/elysia` and exercise the affected path on the project's Bun
version.

Read the [official Elysia skill at the last 1.x revision](https://raw.githubusercontent.com/elysiajs/skills/8fd8031b83bce42e903ed0e38e6170213876c20e/elysia/SKILL.md).
Open the relevant reference from that revision, such as
[WebSockets](https://raw.githubusercontent.com/elysiajs/skills/8fd8031b83bce42e903ed0e38e6170213876c20e/elysia/references/websocket.md)
or [testing](https://raw.githubusercontent.com/elysiajs/skills/8fd8031b83bce42e903ed0e38e6170213876c20e/elysia/references/testing.md).
The [Elysia 1.x documentation index](https://elysiajs.com/llms.txt) links to
specific guides on routing, lifecycle and validation.
